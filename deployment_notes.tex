\section{Node 0 - apt051 (Kafka)}

\subsection{One-time fixes}
Fix hostname resolution:
\begin{lstlisting}
sudo sh -c 'echo "10.10.1.1 node0.mostream-test.pisceslabsd-pg0.apt.emulab.net" >> /etc/hosts'
\end{lstlisting}

\subsection{Start Kafka}
\begin{lstlisting}
cd ~/MoStream
KAFKA_HOST=10.10.1.1 docker compose up -d
\end{lstlisting}

Verify:
\begin{lstlisting}
docker compose ps
\end{lstlisting}

\subsection{Create topics (after every Kafka restart)}
\begin{lstlisting}
docker compose exec kafka kafka-topics --create \
  --topic Simulation --bootstrap-server localhost:9092 \
  --replication-factor 1 --partitions 1

docker compose exec kafka kafka-topics --create \
  --topic Result --bootstrap-server localhost:9092 \
  --replication-factor 1 --partitions 1

# Verify
docker compose exec kafka kafka-topics --list --bootstrap-server localhost:9092
\end{lstlisting}

\subsection{Monitor messages}
\begin{lstlisting}
docker compose exec kafka kafka-console-consumer \
  --bootstrap-server localhost:9092 \
  --topic Simulation --from-beginning --max-messages 5
\end{lstlisting}

\textbf{Hardcoded values (must revisit):}
\begin{itemize}
  \item \texttt{NPMMModel.py}: controlled by \texttt{MOSTREAM\_SKIP\_PRETRAINED} env var
        (default \texttt{"1"} = skip). Pretrained weights from \texttt{model.h5} are incompatible
        (saved with nfp~0.0.x/TF1; EdgeUpdate had 10 weights, current nfp~0.1.3 has 4).
        To enable pretrained weights once professor provides a compatible \texttt{model.h5}:
        \begin{lstlisting}
# On apt063:
echo 'export MOSTREAM_SKIP_PRETRAINED=0' >> ~/flink/conf/flink-env.sh
~/flink/bin/taskmanager.sh stop && ~/flink/bin/taskmanager.sh start
        \end{lstlisting}
  \item \texttt{cloudlab/*.sh}: \texttt{KAFKA\_HOST="10.10.1.1"} - internal IP of apt051.
        Will change if experiment is recreated on different nodes.
  \item \texttt{simulator.py}: \texttt{acks=1} - changed from \texttt{acks=0} which silently
        dropped messages with the Confluent Kafka 3.x broker.
\end{itemize}

\bigskip
\textbf{Known issues:}
\begin{itemize}
  \item Kafka topics wiped on \texttt{docker compose down} - recreate after every restart.
  \item \texttt{systemd-resolved} broken on apt041 - DNS fix (\texttt{nameserver 8.8.8.8})
        is not persistent across reboots; re-apply if node reboots.
  \item \texttt{/etc/resolv.conf} fix on apt041 overwritten if \texttt{systemd-networkd}
        restarts - add \texttt{nameserver 8.8.8.8} to \texttt{/etc/resolv.conf.d/} if persistent fix needed.
  \item Model cold-start: NPMM returns \texttt{model\_not\_ready} until 16 messages accumulate.
  \item No Flink checkpointing - trained weights lost if MDWorkflow crashes.
  \item \texttt{submit\_job.sh} has Windows line endings (\texttt{\textbackslash r\textbackslash n}) when committed from Windows;
        run \texttt{sed -i 's/\textbackslash r//' submit\_job.sh} on CloudLab before executing.
\end{itemize}
